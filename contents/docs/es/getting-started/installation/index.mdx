Configurar **InteraUI** es sencillo y flexible. Puedes instalarlo mediante npm/yarn/pnpm/bun o clonar el repositorio para desarrollo local. Asegúrate de tener [Node.js](https://nodejs.org/) versión 18 o superior para un rendimiento óptimo.

## Clonar Repositorio

Si prefieres trabajar con el código fuente, puedes clonar el repositorio de GitHub y configurar el proyecto manualmente.

<Stepper>
  <StepperItem title="Paso 1: Clonar el Repositorio">
    Clona el repositorio de **intera-ui** desde GitHub:
    
    ```plaintext
    git clone https://github.com/elizabthpazp/intera-ui.git
    ```
  </StepperItem>

  <StepperItem title="Paso 2: Acceder al Proyecto">
    Tras clonar, accede al directorio del proyecto:
    
    ```plaintext
    cd intera-ui
    ```
  </StepperItem>

  <StepperItem title="Paso 3: Instalar Dependencias">
    Instala todas las dependencias necesarias con npm:
    
    ```plaintext
    npm install
    ```
  </StepperItem>

  <StepperItem title="Paso 4: Iniciar el Servidor de Desarrollo">
    Inicia el servidor de desarrollo para probar la librería localmente:
    
    ```plaintext
    npm run dev
    ```
  </StepperItem>
</Stepper>

¡Con esta configuración tendrás **InteraUI** listo para mejorar tu desarrollo de interfaces de forma eficiente!
