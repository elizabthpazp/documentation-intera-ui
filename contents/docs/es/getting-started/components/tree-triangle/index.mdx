En esta guía presentamos el componente `TreeTriangle`, un árbol triangular animado donde las hojas están representadas por líneas giratorias, creando un efecto visual único.

```

export default function Home() {
  return (   
     <TreeTriangle />  
  );
}
```

## Detalles del Componente

El componente `TreeTriangle` consta de:
- Un **árbol con forma triangular** creado con líneas giratorias.
- Un **efecto de animación dinámico** que da la ilusión de movimiento.
- Un **diseño autónomo** que no requiere props adicionales para su personalización.

## Propiedades

El componente `TreeTriangle` no acepta ninguna prop.

### Características

- Usa **animaciones CSS y JavaScript** para un movimiento fluido.
- No requiere configuración adicional: solo importar y usar.
- Diseño responsivo para diferentes tamaños de pantalla.
- Ligero y optimizado para el rendimiento.

Este componente añade un toque moderno y animado a las aplicaciones web con un esfuerzo mínimo.
