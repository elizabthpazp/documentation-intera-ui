En esta guía presentamos el componente `CatLoader`, diseñado para mostrar una animación de carga con un gato para experiencias de carga encantadoras.

## Código

```javascript
import "@elizabthpazp/intera-ui/dist/globals.css";
```

```javascript
import { CatLoader } from "@elizabthpazp/intera-ui";

export default function Home() {
  return (
    <CatLoader />
  );
}
```

## Detalles del Componente

El componente `CatLoader` consta de:
- Un **gato animado** que se mueve en bucle para indicar la carga.
- Una **animación fluida** diseñada para ser visualmente atractiva.
- Una **implementación ligera**, que garantiza un rendimiento óptimo.

## Propiedades

El componente `CatLoader` no acepta ninguna prop; está diseñado como una animación autónoma que puede usarse directamente sin configuración.

### Características

- Divertida **animación de gato** para mejorar las pantallas de carga.
- Rendimiento fluido y optimizado.
- Integración sencilla sin props requeridas.
- Diseño completamente responsivo y adaptable a diferentes tamaños de pantalla.

Este componente añade un toque divertido y atractivo a cualquier estado de carga, mejorando la experiencia del usuario con un elemento visual agradable.
