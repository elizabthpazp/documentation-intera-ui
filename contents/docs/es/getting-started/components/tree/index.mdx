
## Detalles del Componente

El componente `Tree` consta de:
- Una **forma de árbol de Navidad** compuesta por líneas giratorias.
- Un **efecto de animación fluido** que crea una apariencia festiva y dinámica.
- Un **diseño autónomo** que no requiere props adicionales para su personalización.

## Propiedades

El componente `Tree` no acepta ninguna prop.

### Características

- Usa **animaciones CSS y JavaScript** para un movimiento fluido.
- No requiere configuración adicional: solo importar y usar.
- Diseño responsivo para diferentes tamaños de pantalla.
- Ligero y optimizado para el rendimiento.

Este componente añade un toque festivo y animado a las aplicaciones web con un esfuerzo mínimo.
